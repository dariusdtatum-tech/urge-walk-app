## How the loops were made
From the original WAV (BWF) files: a 45 s excerpt (tide from 0:30, shore from 0:20, wind from 0:15,
rain from 0:10), the last 4 s cross-faded into the first 4 s with an equal-power curve so the loop has
no seam, normalized to -3 dBFS, stereo 44.1 kHz, AAC 96 kb/s in .m4a. Each file is about 550 KB
(limit 2 MB). Nothing streams; the app works offline.

Freesound was the first choice but blocks automated downloads from our build machine, so no Freesound
sounds are used. No CC-BY or NC sounds are used.
